## 📌 About the Internship

The internship focused on building a strong practical foundation in Python programming, file-system automation, and software development practices, applied through a real project titled the **Smart File Organizer**. It followed a structured, week-wise progression — beginning with an initial project plan and a basic file-scanning module, and advancing through file categorization, duplicate-file handling, summary statistics, logging, a menu-based user interface, testing, and documentation.

**Organization:** upSkill Campus, an online internship and skilling platform, in collaboration with its industry partner UniConverge Technologies Pvt. Ltd., Noida. The internship was coordinated by Ms. Prabha Singh, HR Manager.

## 🎯 Objectives

- Design and develop a Python-based file-scanning and categorization module
- Implement automatic creation of category folders (Documents, Images, Videos, Audio, Archives, Others)
- Implement safe file-moving logic that prevents accidental overwriting of duplicate filenames
- Add exception handling for file-access and permission-related errors
- Implement summary statistics that report the number of files organized per category
- Add operation logging for successfully organized and skipped files
- Build a simple, menu-based user interface for selecting the directory to organize
- Test the application across varied directory structures and file types
- Prepare project documentation and a testimonial submission summarizing the internship experience

## 🏗️ System Architecture

- **Scanning Layer** – Scans the selected directory and identifies all files present
- **Categorization Layer** – Maps file extensions to categories (Documents, Images, Videos, Audio, Archives, Others)
- **Folder Management Layer** – Automatically creates category folders as required
- **File-Moving & Duplicate-Handling Layer** – Moves files into category folders and renames duplicates so existing files are never overwritten
- **Error-Handling Layer** – Catches and manages file-access, permission, and path-related exceptions without stopping the process
- **Reporting Layer** – Generates summary statistics and operation logs for successful and skipped files
- **Interface Layer** – A simple menu-based interface through which the user selects the directory to organize
